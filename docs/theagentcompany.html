Overview

TheAgentCompany introduces a comprehensive benchmark for evaluating LLM agents on real-world tasks within a simulated software company environment. The benchmark provides an extensible platform that reflects professional settings, allowing assessment of tasks such as web browsing, coding, program execution, and multi-turn communication with colleagues.

Key Metrics

Task Completion Rate: ~30.3% for top-performing models (as reported in the original paper)

Time-to-Completion: Measured in hours per task category

Tool Usage Efficiency: Ratio of useful tool calls to total calls

Communication Fidelity: Accuracy in multi-turn agent communication

Evaluation Framework

# Install TheAgentCompany
git clone https://github.com/All-Hands-AI/the-agent-company.git
cd the-agent-company
pip install -r requirements.txt

# Run evaluation
python -m agentcompany.evaluate --model claude-3.5-sonnet --tasks all

# Check leaderboard
python -m agentcompany.leaderboard --update

Results & Analysis

The benchmark evaluates agents across multiple dimensions:

  • Autonomy: Degree of human intervention required
  • Tool Selection: Quality and relevance of tool choices
  • Reasoning: Quality of chain-of-thought and planning
  • Error Recovery: Ability to handle and recover from failures
  • Communication: Fidelity in multi-agent interactions

Sample Case: Corporate Coding Task

Task: Agents are given a GitHub-style issue and must implement a feature, including code modification, test creation, and documentation updates. The task evaluates the agent's ability to navigate a codebase, understand existing patterns, and produce working code that passes the project's test suite.
