AlphaEvolve — Google DeepMind Evolutionary Coding 2025

ArXiv: arxiv.org/abs/2506.13131 | PDF: arxiv.org/pdf/2506.13131

Core Idea

AlphaEvolve uses evolutionary algorithms combined with LLMs to discover novel algorithms for scientific and mathematical problems. It maintains a population of code solutions, evolves them through mutation and selection, and uses LLMs to generate variations.

How It Works

  1. Population Initialization: Generate initial set of code solutions
  2. Fitness Evaluation: Test each solution on the problem
  3. Selection: Keep top-performing solutions
  4. Mutation via LLM: Use LLM to create variations of good solutions
  5. Evolution Loop: Repeat until convergence or time limit
Results: Discovered novel algorithms for matrix multiplication, sorting, and other problems. Some solutions outperformed human-designed algorithms. Applied to real scientific problems in protein folding and optimization.

Key Innovation

The paper demonstrates that LLMs can be used as mutation operators in evolutionary algorithms. The LLM understands code semantics, making mutations more meaningful than random changes.

Relevance to Our Project

Applies to our continuous improvement goals:

  • Evolve agent prompts through selection and mutation
  • Maintain a population of agent configurations
  • Use fitness functions to evaluate agent performance
  • Automatically discover optimal orchestration strategies
