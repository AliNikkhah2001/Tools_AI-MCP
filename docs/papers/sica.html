SICA — Self-Improving Code Agents 2025

ArXiv: arxiv.org/abs/2504.15228 | PDF: arxiv.org/pdf/2504.15228 | Authors: Google DeepMind

Core Idea

SICA introduces a method where an agent edits itself — it uses its own experience to improve its prompts, tools, and workflows. The agent doesn't just solve tasks; it learns from solving tasks to become better at solving future tasks.

How It Works

  1. Experience Collection: Agent records what worked and what didn't during task execution
  2. Self-Reflection: Agent analyzes its own performance and identifies improvement areas
  3. Self-Modification: Agent updates its own prompts, tool configurations, and strategies
  4. Validation: Modified agent is tested on new tasks to verify improvement
Results: 17-53% improvement on SWE-Bench Verified across multiple models (GPT-4, Claude, Gemini). The self-improvement is compounding — each iteration builds on previous improvements.

Key Innovation

The paper proves that agents can improve themselves without external feedback loops. The improvement is recursive — the improved agent can improve itself further.

Relevance to Our Project

Directly applicable to our vision. We can implement a self-improving loop where our OpenCode agents:

  • Track successful and failed task executions
  • Analyze patterns in their behavior
  • Automatically update their prompts and tool usage
  • Continuously improve without human intervention
