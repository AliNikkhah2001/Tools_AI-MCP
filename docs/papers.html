Academic Papers

5 key papers on self-improving LLM agents and code generation.

SICA (2025) Self-Improvement

Google DeepMind · arxiv.org/abs/2504.15228

Agent edits itself — uses own experience to improve prompts, tools, and workflows. 17-53% improvement on SWE-Bench Verified across GPT-4, Claude, Gemini.

View Details →

Self-Harness (2026) Meta-Learning

arxiv.org/abs/2606.09498

Harnesses that improve themselves — the infrastructure controlling the agent is optimized by the same LLM it controls. 15-52% improvement on Terminal-Bench-2.0.

View Details →

AlphaEvolve (2025) Evolutionary

Google DeepMind · arxiv.org/abs/2506.13131

Evolutionary algorithms combined with LLMs to discover novel algorithms for scientific and mathematical problems. Some solutions outperformed human-designed algorithms.

View Details →

STOP (2024) Safety-Proven

Zelikman et al. · arxiv.org/abs/2310.02304

Mathematically proven safety for recursive self-improvement. Formal safety guarantees that self-improvement preserves safety properties.

View Details →

CER (2025) Memory-Based

Princeton/Stanford · arxiv.org/abs/2506.06698

Contextual experience replay — store experiences with rich context and retrieve based on contextual similarity. Enables learning from past successes and failures.

View Details →

Combined Vision

These 5 papers together provide a complete roadmap:

  • SICA + Self-Harness: Agents that improve themselves at both task and meta levels
  • AlphaEvolve: Evolutionary optimization of agent configurations
  • STOP: Mathematical safety guarantees for recursive improvement
  • CER: Context-aware learning from past experiences
