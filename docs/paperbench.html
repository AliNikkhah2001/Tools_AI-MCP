Overview

PaperBench evaluates AI's ability to replicate published AI research papers. The benchmark measures methodological fidelity, result replication accuracy, and code quality when agents attempt to reproduce published research approaches.

Key Statistics

13+ Papers

AI/ML papers for replication

Result Replication

Numerical accuracy of reproduced results

Methodological Fidelity

Faithfulness to original paper's approach

Code Quality

Completeness and correctness of generated code

Replication Process

  1. Read and understand a published AI research paper
  2. Replicate the methodology as described in the paper
  3. Reproduce the reported results using the same data/code
  4. Generate code that matches the paper's approach
  5. Verify output matches expected results from the paper

Evaluation Metrics

  • Result Accuracy: Numerical closeness to reported results (e.g., loss values, accuracy scores)
  • Methodological Fidelity: Faithfulness to the original paper's approach and assumptions
  • Code Completeness: Percentage of expected code functions/features implemented
  • Documentation Quality: Clarity and completeness of replication documentation

Getting Started

# Install PaperBench
git clone https://github.com/staraceg/PaperBench.git
cd PaperBench
pip install -r requirements.txt

# Replicate a sample paper
python replicate.py --paper "attention-is-all-you-need"

# Run all benchmarks
python run_bench.py --papers all

Sample Replication: Attention Is All You Need

Task: Reproduce the key results from the original Transformer paper "Attention Is All You Need" (Vaswani et al., 2017). Agents must:

  • Implement the Transformer architecture from scratch
  • Train on WMT 2014 English-German translation task
  • Achieve BLEU scores comparable to the original paper
  • Generate training curves matching the reported progression

Replication Success Rates

Benchmark findings indicate:

  • GPT-4 level models achieve ~20-30% full replication success
  • Primary challenge: matching training hyperparameters and data preprocessing
  • Secondary challenge: reproducing exact numerical results due to floating-point variations
  • Methodological replication (architecture, training pipeline) easier than exact result replication
