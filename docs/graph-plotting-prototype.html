Overview

This sample case demonstrates a Python prototype for dynamic graph plotting designed for integration with an Obsidian-style markdown editor. The prototype uses matplotlib with Obsidian-inspired dark mode styling to create compact, visually appealing graphs that can be embedded in markdown content.

Key Features

Obsidian Dark Mode

Color palette inspired by Obsidian: #1e1e1e background, #d4d4d4 text, #bb86fc accent purple

Multiple Series Support

Plot multiple graph series with distinct colors and legends

Export Formats

Export graphs to PNG or SVG format for markdown embedding

Interactive Hover

Tooltip support for data point exploration

Usage

  1. Import ObsidianGraphPlotter from the prototype
  2. Create an instance: plotter = ObsidianGraphPlotter(width=800, height=600)
  3. Generate data: t, y = plotter.generate_sine_wave(frequency=2.0)
  4. Create plot: fig, ax = plotter.create_static_plot([(t, y, color, 'Label')])
  5. Export: plotter.export_figure(fig, format='png', path='graph.png')

Technical Details

  • Library: matplotlib (Python standard plotting library)
  • Styling: Obsidian-inspired dark color scheme
  • Output: PNG (raster) or SVG (vector) format
  • Layout: Compact design for markdown editor integration
  • Features: Multi-series support, hover tooltips, dark mode

Integration with Obsidian

The generated graphs can be embedded in Obsidian markdown using:

![[graph.png|600]]

or linked as SVG for scalable graphics:

![graph.svg]

The dark mode styling ensures the graphs blend seamlessly with Obsidian's default theme.
