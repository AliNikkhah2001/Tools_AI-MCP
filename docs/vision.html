The Vision: LLM-Controlled Coding Pipeline

Core Idea: Build a system where an LLM controls OpenCode to continuously prompt, accept permissions, and never stop coding — like a company software development pipeline with planner, code reviewer, documenter agents and a progress dashboard.

Why This Exists

Current LLM coding tools have fundamental limitations:

  • Single-shot interaction: You prompt once, get one response, done
  • No continuous operation: The system stops after each task
  • No permission auto-accept: Human must approve every dangerous action
  • No quality gates: No review process, no testing, no validation
  • No progress tracking: No dashboard, no metrics, no visibility

Key Components

1. Multi-Agent Orchestration

The system uses multiple specialized agents working together:

  • Planner Agent: Breaks goals into actionable tasks
  • Coding Agents: Backend, Frontend, ML specialists
  • Review Agent: Quality assurance and code review
  • Security Agent: Vulnerability scanning and compliance
  • Documenter Agent: Documentation generation
  • Test Agent: Test writing and execution

2. Continuous Operation

The system never stops. It continuously:

  • Monitors for new tasks or issues
  • Picks up work from the queue
  • Self-corrects when errors occur
  • Improves its own prompts and processes

3. Permission Auto-Accept

Smart permission management based on risk levels:

  • Low risk: Auto-approve (reading files, small edits)
  • Medium risk: Auto-approve with logging
  • High risk: Require human confirmation

4. Progress Dashboard

Real-time monitoring of the entire pipeline:

  • Task completion status
  • Agent activity logs
  • Code quality metrics
  • Error rates and resolution
  • Performance benchmarks

Academic Foundations

This vision is backed by 5 key research papers:

  • SICA (2025): Self-Improving Code Agents — 17-53% gains on SWE-Bench
  • Self-Harness (2026): Harnesses that improve themselves — 15-52% gains
  • AlphaEvolve (2025): Google DeepMind evolutionary coding for scientific discovery
  • STOP (2024): Recursively self-improving code generation with safety proofs
  • CER (2025): Contextual Experience Replay for agent self-improvement
