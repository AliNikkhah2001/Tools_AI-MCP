Overview

ScienceAgentBench is a benchmark for evaluating language agents on data-driven scientific discovery tasks. Agents write and execute Python programs that process real-world scientific data and produce output files, which are graded by task-specific evaluation scripts.

Task Structure

Each task includes:

  • Input data files (real scientific datasets)
  • Context description and objectives
  • Evaluation scripts (task-specific grading)
  • Expected output files for validation

Evaluation Metrics

  • Code Execution Success: Percentage of tasks where agent code runs without errors
  • Data Analysis Correctness: Accuracy of statistical tests and visualizations
  • Output File Generation: Correct generation of expected output files
  • Reproducibility: Ability to reproduce results with provided code
