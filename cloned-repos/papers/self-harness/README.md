# Self-Harness: Harnesses That Improve Themselves

## Paper Details
- **Title:** Self-Harness: Harnesses That Improve Themselves
- **Year:** 2026
- **ArXiv:** https://arxiv.org/abs/2606.09498
- **PDF:** https://arxiv.org/pdf/2606.09498

## Core Idea
The harness (infrastructure controlling the agent) is optimized by the same LLM it controls.

## Performance
- 15-52% improvement on Terminal-Bench-2.0
- Harness improvement is transferable across task types

## Key Innovation
Meta-prompting - LLM writes prompts that control itself.

## Relevance
Orchestrator can improve its own task routing logic.
