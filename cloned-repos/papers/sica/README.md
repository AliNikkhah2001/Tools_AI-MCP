# SICA: Self-Improving Code Agents

## Paper Details
- **Title:** Self-Improving Code Agents via In-Context Reinforcement Learning
- **Authors:** Google DeepMind
- **Year:** 2025
- **ArXiv:** https://arxiv.org/abs/2504.15228
- **PDF:** https://arxiv.org/pdf/2504.15228

## Core Idea
Agent edits itself - uses own experience to improve prompts, tools, and workflows.

## Performance
- 17-53% improvement on SWE-Bench Verified
- Works across GPT-4, Claude, Gemini
- Recursive improvement (improved agent improves further)

## Key Innovation
Agents can improve themselves without external feedback loops.

## Relevance
Directly applicable to OpenCode multi-agent system self-improvement.
