# AlphaEvolve: Google DeepMind Evolutionary Coding

## Paper Details
- **Title:** AlphaEvolve: A coding agent for scientific and algorithmic discovery
- **Year:** 2025
- **ArXiv:** https://arxiv.org/abs/2506.13131
- **PDF:** https://arxiv.org/pdf/2506.13131

## Core Idea
Evolutionary algorithms combined with LLMs to discover novel algorithms.

## Performance
- Novel algorithms for matrix multiplication, sorting
- Some solutions outperformed human-designed algorithms
- Applied to protein folding and optimization

## Key Innovation
LLMs as mutation operators in evolutionary algorithms.

## Relevance
Evolve agent prompts through selection and mutation.
