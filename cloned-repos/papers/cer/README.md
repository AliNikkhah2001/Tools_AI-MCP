# CER: Contextual Experience Replay

## Paper Details
- **Title:** Contextual Experience Replay for Language Agents
- **Year:** 2025
- **ArXiv:** https://arxiv.org/abs/2506.06698
- **PDF:** https://arxiv.org/pdf/2506.06698

## Core Idea
Store experiences with rich context, retrieve based on contextual similarity.

## Performance
- Significant improvement on agent benchmarks
- Context-aware retrieval outperforms simple storage

## Key Innovation
"Contextual similarity" - matching why approaches worked, not just task type.

## Relevance
Store agent experiences with context, retrieve for new tasks.
